Projects

Highlights from blockchain protocols to production web apps

Web3 · Full-Stack

Blockchain Identity & Document Workflow Platform

Problem: Traditional KYC/KYB systems expose raw PII, lack auditability, and provide no user-controlled data sharing or verifiable credential portability.

Solution: Built a full-stack identity and document workflow platform combining a Next.js frontend, Express backend, and Solidity smart contracts. Features include KYC/KYB review workflows, soulbound identity tokens (non-transferable on-chain proof), selective data-access control, wallet-based document signing (DocuSign-style envelopes with EIP-712), transaction proof tokenization, encrypted off-chain storage via IPFS/Pinata, and role-based admin/verifier dashboards — keeping sensitive data off-chain while preserving on-chain verifiability.

Solidity Hardhat OpenZeppelin Next.js Node.js / Express MongoDB IPFS / Pinata Wagmi RainbowKit EIP-712
